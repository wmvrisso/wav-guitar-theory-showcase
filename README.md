# WAV Guitar Theory

WAV Guitar Theory is an interactive learning and composition tool for beginner and intermediate guitarists. It translates music-theory concepts, genre, and mood into playable musical ideas through a visual guitar interface.

## Live Application

[Launch WAV Guitar Theory](https://wav-guitar-theory.onrender.com)

## Overview

WAV Guitar Theory helps guitarists explore notes, chords, scales, and progressions while seeing their location on the fretboard in real time. The application combines theory tools with performance controls so users can move naturally between learning, experimentation, and composition.

## Features

- Interactive guitar fretboard with real-time note visualization
- Controls for mode, root, chord family, genre, and mood
- Playable notes, chords, scales, and progressions
- Multiple chord variations
- Adjustable tempo and built-in metronome
- ARP, LOOP, GATE, and LATCH performance controls
- Sound slots for organizing musical ideas
- Short-form audio recording and clip download
- Volume and playback controls
- Browser-based access without installation

## Product Direction

WAV Guitar Theory is designed as both a standalone learning tool and part of the broader WAV product ecosystem. Its theory data and musical controls are being explored for future integration with the WAV Sampler Engine, clip playback, and sequencing concepts.
